## Conclusion

The given song IDs were successfully inserted into a hash table
using the Division Method with Linear Probing.

The table size was 10 and the load factor was 0.8. Several
collisions occurred because many song IDs generated the same
hash index.

Hashing required 20 operations for the given successful searches,
whereas linear search required 36 comparisons.

Therefore, hashing provides better average search performance
for this application. However, the hash-table size and hash
function should be selected properly to reduce collisions.
